PowerSimulationsDecomposition.jl

PowerSimulationsDecomposition extends PowerSimulations with subsystem-filtered regional optimization containers, split-area PTDF modeling, state-estimation parameters, and sequential result aggregation. It is intended for researchers who already understand PowerSystems data and PowerSimulations templates.

The structure follows PowerSimulations' separation of tutorials, how-to guides, explanations, and reference material, but covers only this package's implemented extensions. The support reference identifies evidence and limits: in particular, MPI (Message Passing Interface) execution is incomplete, while reserve-deliverability coverage is limited to the documented tested cases. MPI is a standard for communication between processes in parallel programs, not a convergence algorithm. There is no automatic partitioning, convergence guarantee, or global-optimality equivalence claim.

Solid arrows denote data supplied to a consumer; the dashed arrow denotes Julia method extensions, not ownership of PowerSimulations. PowerSystems owns component data; this package does not split it into independently copied Systems. See the extension lifecycle for construction calls.

Project and institution

Source and issue tracking are at NLR-Sienna/PowerSimulationsDecomposition.jl. The default branch is main. No published stable/dev manual was available when these documentation destinations were checked; a successful local build is not a deployment.

The current laboratory name is National Laboratory of the Rockies (NLR). Historical attribution and the BSD license are preserved in the repository.
