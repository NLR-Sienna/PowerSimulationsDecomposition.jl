Developer guide

Read the lifecycle before changing extension dispatch, and the workflow before selecting checks. Computational behavior lives in Julia source and tests; this manual is not a substitute for verifying the resolved PowerSimulations 0.38.x interfaces targeted by the dependency upgrade.

Run the local development checks

Start from the repository root in PowerShell with Julia 1.10+ (the documentation CI tracks the latest stable Julia 1.x release). The local development cycle provides a copyable runbook:

TaskInstructions
Format Julia and MarkdownRun the repository formatter; it modifies files across the checkout
Run regression testsRun all tests or select test files, including the runner's Aqua checks
Prebuild and preview the manualBuild documentation locally; the build also executes the tutorial

Inspect the resulting diff before committing. A successful local prebuild does not deploy the manual or prove that remote CI passed.

Reading order

The entry point imports dependencies and declares aliases before including core types, templates/containers, algorithms, the DecisionModel extension, network/ branch methods, and display methods. Add new definitions before their consumers, and verify the exact PSI method signatures against the resolved dependency.
