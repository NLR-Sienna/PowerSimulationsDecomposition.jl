Public API

These are the five bindings exported by this package. Constructors and formulations use PowerSystems data and PowerSimulations modeling interfaces; PSI's setters, DecisionModel, build!, solve!, and result readers are not re-exported here.

PowerSimulationsDecomposition.MultiProblemTemplate — Type
MultiProblemTemplate(base_template::PSI.ProblemTemplate, problem_keys::Vector{String})
MultiProblemTemplate(network::PSI.NetworkModel, problem_keys::Vector{String})

Create a base template and a deep-copied regional template for each subsystem key.

Use PowerSimulations' model setters to configure the templates. Keys identify existing PowerSystems named subsystems; this constructor does not assign components or infer a partition. DecisionModel construction copies and finalizes the templates, removing empty regional device and branch models.

source
PowerSimulationsDecomposition.MultiRegionProblem — Type
MultiRegionProblem

Select sequential regional construction and execution in a PowerSimulations model.

Construct the model with PSI.DecisionModel(MultiRegionProblem, template, sys; kwargs...), where template is a MultiProblemTemplate. The model uses one PSI optimization container per subsystem and joins dense results for PSI storage. It does not perform an iterative coordination solve. The constructor selects the internal SequentialAlgorithm; MPI (Message Passing Interface) execution is incomplete.

source
PowerSimulationsDecomposition.SplitAreaPTDFPowerModel — Type
SplitAreaPTDFPowerModel

Model subsystem-filtered area balances with PTDF network context.

Local injections enter area and nodal expressions. Internal state-estimation parameters supply nonregional nodal injections in system-base per-unit quantities. Optional area-interchange flows enter the from-area balance negatively and the to-area balance positively. Configure this formulation through PSI.NetworkModel. Subsystem membership must be supplied explicitly.

source
PowerSimulationsDecomposition.StaticBranchUnboundedStateEstimation — Type
StaticBranchUnboundedStateEstimation

Reconstruct monitored-line PTDF flows from baseline flows and injection changes.

The concrete construction methods support PSY.MonitoredLine with a PSI PTDF network model. Baseline parameters use system-base per-unit quantities. This unbounded formulation does not add branch-rating inequalities; feedforward constraints are attached through PSI.

source
PowerSimulationsDecomposition.NetworkFlowConstraintStateEstimation — Type
NetworkFlowConstraintStateEstimation

Identify the equality registered for state-estimation PTDF flow expressions.

Use this PSI constraint key with StaticBranchUnboundedStateEstimation. The flow builder mutates the registered expression store before constructing the equality. This key does not identify a thermal branch-rating inequality.
