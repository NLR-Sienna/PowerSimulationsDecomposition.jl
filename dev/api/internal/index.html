Internal extensions

These bindings are not exported and are version-sensitive implementation details. Qualify them with PowerSimulationsDecomposition when inspecting them. Prefer the public API for user code.

PowerSimulationsDecomposition.DecompositionAlgorithm — Type
DecompositionAlgorithm

Identify the internal dispatch family for regional container algorithms.

source
PowerSimulationsDecomposition.SequentialAlgorithm — Type
SequentialAlgorithm

Build regional containers and solve each once per model execution.

Iteration follows the subproblem dictionary. This internal algorithm aggregates results only after all regional solves succeed; it has no convergence loop.

source
PowerSimulationsDecomposition.MPIParallelAlgorithm — Type
MPIParallelAlgorithm

Identify the incomplete internal MPI (Message Passing Interface) execution scaffold.

The solve method contains unresolved names and does not provide a supported parallel execution path.

source
PowerSimulationsDecomposition.MultiOptimizationContainer — Type
MultiOptimizationContainer(algorithm, sys, settings, time_series_type, subproblem_keys)

Create the internal regional PSI containers and joint optimization stores.

The algorithm argument is a concrete DecompositionAlgorithm type. Each key identifies a regional container; bus maps are populated during the build. The System must provide a single time-series resolution and the time-series type must be concrete. Initialization sets the System's units to SYSTEM_BASE. The main container is not a solved central coordination problem.

source
PowerSimulationsDecomposition.StateEstimationInjections — Type
StateEstimationInjections

Identify internal baseline nodal-injection parameters on PSY.ACBus.

Values initialize to zero with unit multipliers and use bus-number strings and time indices. Simulation updates read ActivePowerBalance expression state in system-base per-unit quantities. No general resampling contract is implemented.

source
PowerSimulationsDecomposition.StateEstimationFlows — Type
StateEstimationFlows

Identify internal baseline flow parameters on PSY.MonitoredLine.

Values initialize to zero with unit multipliers and use branch names and time indices. Simulation updates read PTDFBranchFlow expression state in system-base per-unit quantities.
